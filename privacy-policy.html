Usblk 隐私政策

开发者：ice Studio
联系方式：idotceus@gmail.com
生效日期：20261118

Usblk 提供 USB、串口、本机终端、ADB、SSH 和 USB 音视频功能。使用相关功能时，应用可能请求 USB、相机或麦克风权限。终端命令和通信内容发送到用户选择的本机环境、USB 设备或 SSH 服务器。

应用在本地保存设置、最近会话、SSH 主机资料和服务器指纹；SSH 密码不保存在主机资料中。ADB 密钥和可能包含通信内容的串口日志保存在应用私有存储；新建日志时清理较旧日志，单次日志约 8 MiB 后停止写入。清除应用数据或卸载通常会删除应用私有数据。

照片、录音及用户导出的日志保存在用户授权的内部存储 Documents/Usblk 目录。共享文件在卸载后可能保留，可使用文件管理器删除。

应用使用 Google AdMob 和 User Messaging Platform。根据地区、设备、配置和用户选择，Google 及广告合作方可能处理 IP 地址、设备或广告标识符、应用交互和诊断信息，用于广告、分析或防欺诈。适用时应用提供隐私选择，并可在设置中的广告隐私选项调整。Google 数据使用说明：https://policies.google.com/technologies/partner-sites

应用使用 Android 权限和私有存储保护本地数据，并在首次 SSH 连接时要求确认服务器指纹。用户可以在系统设置管理权限、清除应用数据或卸载，并自行删除共享文件。广告合作方的数据处理受其政策和可用选择约束。隐私问题请联系上述开发者；功能或数据处理变化时应更新本政策。

Usblk Privacy Policy

Developer: ice Studio
Contact: idotceus@gmail.com
Effective date: 20261118

Usblk provides USB, serial, local terminal, ADB, SSH and USB audio/video features. It requests USB, camera or microphone access when needed. Commands and communication data are sent to the local environment, USB device or SSH server you select.

Settings, recent sessions, SSH host details and server fingerprints are stored locally; SSH passwords are not saved in host profiles. ADB keys and serial logs, which may contain communication data, are stored in private app storage. Older logs are removed when new logs are created; each log stops at approximately 8 MiB. Clearing app data or uninstalling normally deletes private data.

Photos, audio recordings and exported logs are saved to the user-authorized Documents/Usblk directory in internal storage. Shared files may remain after uninstalling and can be deleted with a file manager.

The app uses Google AdMob and User Messaging Platform. Depending on region, device, configuration and user choices, Google and its advertising partners may process IP addresses, device or advertising identifiers, app interactions and diagnostic information for advertising, analytics or fraud prevention. Where applicable, the app presents privacy choices that can be changed under advertising privacy options in settings. Google data use: https://policies.google.com/technologies/partner-sites

Android permissions and private storage help protect local data. SSH server fingerprints require confirmation on first connection. You can manage permissions, clear app data or uninstall, and delete shared files. Advertising partners process data under their policies and available choices. Contact the developer above with privacy questions; this policy should be updated when features or data handling change.

Usblk プライバシーポリシー

開発者：ice Studio
連絡先：idotceus@gmail.com
施行日：20261118

Usblk は USB、シリアル、ローカル端末、ADB、SSH、USB 音声・映像機能を提供し、必要に応じて USB、カメラ、マイクへのアクセスを求めます。コマンドや通信データは選択したローカル環境、USB 機器または SSH サーバーに送信されます。

設定、最近の接続、SSH ホスト情報とサーバーの指紋を端末内に保存します。SSH パスワードはホスト情報に保存しません。ADB 鍵と通信内容を含む場合があるシリアルログはアプリ専用領域に保存されます。新しいログの作成時に古いログを削除し、各ログは約 8 MiB で記録を停止します。データ消去やアンインストールにより専用データは通常削除されます。

写真、録音およびエクスポートしたログはユーザーが許可した内部ストレージの Documents/Usblk に保存されます。共有ファイルはアンインストール後も残る場合があり、ファイル管理アプリで削除できます。

Google AdMob と User Messaging Platform を使用します。地域、端末、設定、ユーザーの選択に応じ、Google と広告パートナーは広告、分析、不正防止のため IP アドレス、端末または広告識別子、アプリの操作情報、診断情報を処理する場合があります。該当する場合、アプリはプライバシーの選択を表示し、設定の広告プライバシーオプションから変更できます。Google の説明：https://policies.google.com/technologies/partner-sites

Android の権限と専用領域でローカルデータを保護し、SSH 初回接続時にサーバーの指紋を確認します。権限の管理、アプリデータの消去、アンインストール、共有ファイルの削除が可能です。広告パートナーのデータ処理には各社のポリシーと選択肢が適用されます。お問い合わせは上記の連絡先へお願いします。機能やデータの取扱いが変わる場合、本ポリシーを更新します。

개발자: ice Studio
연락처: idotceus@gmail.com
시행일: 20261118

Usblk는 USB, 시리얼, 로컬 터미널, ADB, SSH 및 USB 오디오/영상 기능을 제공합니다. 필요한 경우 USB, 카메라 또는 마이크 접근 권한을 요청합니다. 명령과 통신 데이터는 사용자가 선택한 로컬 환경, USB 기기 또는 SSH 서버로 전송됩니다.

설정, 최근 세션, SSH 호스트 정보와 서버 지문을 기기에 저장합니다. SSH 비밀번호는 호스트 정보에 저장하지 않습니다. ADB 키와 통신 내용이 포함될 수 있는 시리얼 로그는 앱 전용 저장소에 저장합니다. 새 로그 생성 시 오래된 로그를 삭제하고 각 로그는 약 8 MiB에서 기록을 중단합니다. 앱 데이터 삭제 또는 제거 시 전용 데이터는 일반적으로 삭제됩니다.

사진, 녹음 및 내보낸 로그는 사용자가 권한을 부여한 내부 저장소의 Documents/Usblk 폴더에 저장됩니다. 공유 파일은 앱 제거 후에도 남을 수 있으며 파일 관리자로 삭제할 수 있습니다.

Google AdMob과 User Messaging Platform을 사용합니다. 지역, 기기, 설정 및 사용자 선택에 따라 Google과 광고 파트너는 광고, 분석 또는 부정행위 방지를 위해 IP 주소, 기기 또는 광고 식별자, 앱 상호작용 및 진단 정보를 처리할 수 있습니다. 해당되는 경우 앱에서 개인정보 선택 항목을 제공하며 설정의 광고 개인정보 옵션에서 변경할 수 있습니다. Google 데이터 사용: https://policies.google.com/technologies/partner-sites

Android 권한과 전용 저장소로 로컬 데이터를 보호하며 SSH 최초 연결 시 서버 지문을 확인합니다. 권한을 관리하고 앱 데이터를 지우거나 앱을 제거하고 공유 파일을 삭제할 수 있습니다. 광고 파트너의 데이터 처리에는 해당 업체의 정책과 선택 옵션이 적용됩니다. 개인정보 문의는 위 연락처로 보내 주세요. 기능이나 데이터 처리가 변경되면 이 방침을 업데이트합니다.
